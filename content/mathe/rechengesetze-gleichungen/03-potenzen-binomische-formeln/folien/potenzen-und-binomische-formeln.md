# "Eine Klammer, zwei Antworten"

Wie lautet $(x + 3)^2$ ausmultipliziert?

## Links: "Lisa"
$x^2 + 9$

## Rechts: "Tom"
$x^2 + 6x + 9$

---

Wer hat recht? Teste mit $x = 2$.

::platz

::bis 9:00

::notiz
Einzelarbeit, danach Partnervergleich und gemeinsame Besprechung. Die Probe mit einer konkreten Zahl ist der Schlüssel: Lisas Fehler ist die häufigste Fehlvorstellung bei Potenzen von Summen.

Probe mit $x = 2$:

- Ausgangsterm: $(2 + 3)^2 = 25$
- Lisa: $2^2 + 9 = 13$ (falsch)
- Tom: $2^2 + 6 * 2 + 9 = 25$ (richtig)

Bei Lisa fehlt der **mittlere Teil**.

# "Klammer mit sich selbst multiplizieren"

$(x + 3)^2 = (x + 3)(x + 3)$

Multipliziere aus. Woher kommt der mittlere Teil?

::platz

::bis 11:00

::notiz
Schrittweise an der Tafel entwickeln, Lernende diktieren lassen:

$(x + 3)^2 = (x + 3)(x + 3)$

$= x * x + x * 3 + 3 * x + 3 * 3$

$= x^2 + 3x + 3x + 9$

$= x^2 + 6x + 9$

Die beiden gemischten Produkte ergeben zusammen den mittleren Teil. Frage: Woher kommt $6x$?

# "Fehler jagen"

Welche Umformungen sind richtig?

1. $x^2 * x^3 = x^6$
2. $(2x)^2 = 4x^2$
3. $-3^2 = 9$
4. $x^2 + x^3 = x^5$

::bis 40:00

::notiz
Handzeichen oder Partnergespräch, Begründungen verlangen. Die vier Fälle entsprechen den typischen Fehlern aus dem Kapitelinhalt: Exponenten multiplizieren statt addieren, Faktor in der Klammer vergessen, Vorzeichen, Summe zusammenfassen.

1. Falsch: $x^2 * x^3 = x^5$, die Exponenten werden addiert.
2. Richtig: $(2x)^2 = 2^2 * x^2 = 4x^2$
3. Falsch: $-3^2 = -9$, die Potenz wird zuerst berechnet.
4. Falsch: $x^2 + x^3$ lässt sich nicht zusammenfassen.

# "Zum Mitnehmen"

- Das Quadrat einer Summe ist **nicht** die Summe der Quadrate.
- Der mittlere Teil ist $2 a b$.
- Potenzen mit gleicher Basis: **Exponenten addieren** beim Multiplizieren, **subtrahieren** beim Dividieren.
- Beim Potenzieren einer Potenz **multiplizieren** wir die Exponenten.
